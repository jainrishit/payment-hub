Bank Simulation

Simulate bank processing of SENT payments. Payments are processed asynchronously and assigned realistic outcomes such as Settled (successful processing), Returned (e.g., insufficient funds, invalid account), or Failed (processing/system errors). This models real-world ACH behavior where not all payments succeed, enabling testing of lifecycle tracking, reconciliation, and error handling. Outcomes are determined using randomized simulation to mimic real-world variability.

POST /simulate-bank

Process sent payments and update their status based on simulated bank outcomes

3. Generate NACHA File
→ NACHA file created and stored
→ File linked to batch
→ File visible in UI (Files tab)
→ Status: Sent

NACHA Disclaimer: NACHA files generated in this system are structurally accurate representations used for simulation purposes. In production systems, NACHA files require strict validation, bank-specific configurations, secure transmission protocols, and comprehensive compliance checks before being accepted by financial institutions.
